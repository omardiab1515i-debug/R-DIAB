R-DIAB RESTRICTED PROXY STARTER

Deploy:
1. Connect this GitHub repository to a Render Web Service.
2. Render detects render.yaml. Set ALLOWED_HOSTS to exact hostnames you own
   or have explicit permission to proxy, separated by commas.
   Example: docs.example.org,portal.example.org
3. Deploy.

This is not an open proxy and must not be used to bypass school, workplace,
or network restrictions. Many sites block iframe display or reverse proxying;
login, cookies, scripts, and some pages may not work.
